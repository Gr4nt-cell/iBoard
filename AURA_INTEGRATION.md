# AURA realistic 3D collection — expanded prototype

The bundled collection contains 160 mapped emoji entries across 10 artwork rows (165 PNG files including previous assets).
AURA is the **only** emoji art renderer. Emoji import and style selection are absent. The picker displays only Unicode entries with AURA assets.
The new artwork was extracted from a promotional concept sheet and upscaled to 512x512; it is **not** a native high-resolution master, nor a full Unicode emoji set.
Individual icons may contain compositing artifacts or cropped details and need production-quality redraws.
Unicode characters inserted into other applications are rendered by those applications / the OS, not by this keyboard.
No APK was built or tested.
