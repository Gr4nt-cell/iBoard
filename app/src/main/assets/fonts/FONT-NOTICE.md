# AURA Emoji font notice

`aura-emoji.ttf` (family "AURA Emoji") is iBoard's bundled colour emoji font.
Every glyph was generated for iBoard with AI image tools in the AURA style: Figma AI (one image
per emoji), OpenArt (Nano Banana 2) and Gamma (4x4 sheets, cut into single emoji). They are
assembled into a CBDT colour font with Noto Emoji's build tools (Apache License 2.0).

The set grows in batches. Emoji not yet in the font are hidden from iBoard's emoji picker.
The build pipeline and source images are in `design/aura-emoji/`.
