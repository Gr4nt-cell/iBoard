# iBoard 1.0.45

Built from commit after 961fd21 (version code 45).

- AURA Stickers: 229 die-cut stickers made from the AURA emoji art, in seven packs: Words
  (captioned: LOL, Thank you, Good morning, On my way…), Smileys, Love, Hands, Animals, Food, Party.
- AURA GIFs: 48 animated cards (bounce, heartbeat, wave, confetti, hearts, zzz…), most with captions.
- Tap a sticker or GIF to insert it in the chat. If an app doesn't take images from keyboards,
  a short notice says so.

The signed AAB (113 MB) is stored with Git LFS because it is over GitHub's 100 MB file limit.
The universal APK (128 MB) is delivered separately.

Signed with the Play upload key (alias `upload`).
