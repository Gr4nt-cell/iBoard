# iBoard 1.0.49

- Settings › Icon Capsule › Buttons on Suggestion Bar: pick up to two of the six capsule buttons
  (Settings, Emoji, Languages, Dictation, Clipboard, Translator) to sit on the suggestion bar,
  one on the left and one on the right. A button on the suggestion bar is removed from the capsule,
  and turning it off puts it back.
- Includes 1.0.47: stickers and GIFs are optional downloads.

`iBoard-v1.0.49-arm64.apk` installs on 64-bit phones. The AAB is for Play. Both signed with the upload key.
