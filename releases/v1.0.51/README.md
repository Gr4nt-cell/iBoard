# iBoard 1.0.51

New keyboard languages (Settings › Languages):

- Turkish (Türkçe): Turkish Q layout with ı ğ ü ş i ö ç.
- Italian, Polish, Danish (æ ø å) and Czech (QWERTZ with ú ů); long-press for accents.
- Hindi (हिन्दी): Devanagari layout; long-press for aspirated letters (क → ख), vowels (ा → आ), ।
- Korean (한국어): 2-set layout, letters join into syllables as you type; shift for ㄲ ㄸ ㅃ ㅆ ㅉ ㅒ ㅖ.
- Chinese (简体中文, Pinyin): type pinyin, pick characters from the bar; space picks the first one,
  return keeps the letters. Whole phrases work too (woaini → 我爱你).

Word predictions for all new languages; no autocorrect for Hindi, Korean and Chinese.
Online and offline dictation use the selected language.

`iBoard-v1.0.51-arm64.apk` installs on 64-bit phones. The AAB is for Play. Both signed with the upload key.
