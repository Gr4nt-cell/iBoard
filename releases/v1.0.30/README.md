# iBoard 1.0.30

Built from commit 615b304 (version code 30, targets Android 16 / API 36).

What's new:
- AURA 3D emoji artwork (500 emoji) is the only emoji style; no emoji import or style choice.
- Gemoji and all earlier emoji art removed.
- The voice model is no longer built in. Download Fast (Whisper Tiny, ~31 MB), Balanced
  (Whisper Base, 57 MB) or Accurate (Whisper Small, ~181 MB) in Settings › Voice Model.
  Adds the INTERNET permission, used only for that download.

Both files are signed with the Play upload key (alias `upload`, SHA-256
`A1:8A:17:FD:F9:D9:9D:0C:BD:7D:AA:BB:4C:EF:99:10:CD:B3:30:C4:71:84:A3:0E:59:1C:34:34:F5:DC:7E:39`).
