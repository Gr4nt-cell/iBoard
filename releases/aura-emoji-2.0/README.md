AURA Emoji font, 1,652 emoji.

- **AURA-Emoji.ttf**: the AURA set alone (CBDT colour font). Only the 1,652 AURA emoji are in it, so other emoji fall back to your system font.
- **AURA-Emoji-Full.ttf**: a complete emoji font (about 4,000 emoji). AURA wherever it exists, Google's Noto 3D emoji (SIL Open Font License) for the rest. Use this one to replace a phone's emoji font.
- **AURA-Emoji-Magisk.zip**: the full font as a Magisk / KernelSU / APatch module for rooted Android phones. Install from Modules, then reboot.
