AURA Emoji font 3.0: every standard emoji (3,963), including all skin tones, mixed-tone couples and flags.

- **AURA-Emoji.ttf**: the full AURA set (CBDT colour font, 160 px).
- **AURA-Emoji-Full.ttf**: AURA as a drop-in replacement for Android's NotoColorEmoji.ttf (136×128, same glyph layout as Noto).
- **AURA-Emoji-Magisk.zip**: Magisk / KernelSU / APatch module (author gr4nt). Install from Modules, reboot.

Flags come from Google's Noto Emoji 3D font (SIL Open Font License 1.1).
