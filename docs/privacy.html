iBoard privacy

Updated 4 November 2026

Your keyboard works on your phone

iBoard uses the internet only to download a voice model you choose. Nothing you type or say is uploaded. Microphone access is optional and is used only for dictation you start. It has no cloud APIs, accounts, ads or analytics. Predictions, corrections, emoji and clipboard tools operate on the device.

Local data

Settings, learned words and word combinations, emoji history, skin-tone choices, downloaded voice models and clipboard history stay in private app storage. Password fields disable suggestions. Fields marked incognito do not teach the dictionary. Android backup is disabled.

You can disable learning or reset learned words in Settings, disable clipboard history, clear clipboard items and delete downloaded voice models. Uninstalling removes the app's private data.

Emoji rendering

The keyboard uses the bundled, restyled AURA color font. Unsupported emoji sequences are not drawn with Android's fallback font. Font importing is unavailable. Other apps render Unicode emoji using their own fonts.

Removed features

The offline update removes cloud prediction, translation, grammar rewriting and cloud dictation. It clears old provider settings and API keys, cancels obsolete model downloads and removes their files.

Dictation and voice model downloads

Dictation needs a Whisper voice model, which you download once from Settings › Voice Model. The file comes from Hugging Face (huggingface.co, the whisper.cpp model repository) through Android's download manager; that server sees an ordinary download request (such as your IP address), and no other information is sent. After the download, the model processes microphone audio in memory on your device. Audio is not saved or transmitted. A deliberate microphone tap and Android microphone permission are required.

Permissions

Internet is used only for voice model downloads. Vibration provides optional key feedback. Android's input-method binding permission lets the system connect the keyboard. No screen recording is used for blur. Text and Unicode emoji you choose to type are sent to the app in which you are typing.
