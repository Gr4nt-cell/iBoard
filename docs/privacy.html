iBoard privacy

Updated 1 November 2026

Your keyboard works offline

iBoard has no internet permission. Microphone access is optional and is used only for dictation you start. It has no cloud APIs, accounts, ads or analytics. Predictions, corrections, emoji and clipboard tools operate on the device.

Local data

Settings, learned words and word combinations, emoji history, skin-tone choices, optional imported fonts and clipboard history stay in private app storage. Password fields disable suggestions. Fields marked incognito do not teach the dictionary. Android backup is disabled.

You can disable learning or reset learned words in Settings, disable clipboard history, clear clipboard items and remove an imported font. Uninstalling removes the app's private data.

Removed features

The offline update removes cloud prediction, translation, grammar rewriting and cloud dictation. It clears old provider settings and API keys, cancels obsolete model downloads and removes their files.

Offline dictation

The bundled Whisper model processes microphone audio in memory on your device. Audio is not saved or transmitted. A deliberate microphone tap and Android microphone permission are required. Close the keyboard or change fields to cancel. No model download is required.

Permissions

Vibration provides optional key feedback. Android's input-method binding permission lets the system connect the keyboard. No screen recording is used for blur. Text and Unicode emoji you choose to type are sent to the app in which you are typing.
